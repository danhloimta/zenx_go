## Change checklist

When a feature changes:

1. Update the owning domain document and its screen/API catalog rows.
2. Update this matrix's status/source/test references.
3. Change `Last verified` and `Verified commit` in the affected docs.
4. Re-check moved-document links and confirm the relevant automated test or record a test gap.
